### ▶ [เล่นเลย (เวอร์ชันทดลองบนเว็บ)](https://jprk9939.github.io/elysmar-online/)

เวอร์ชันบนเว็บเป็น **โหมดออฟไลน์ (เล่นคนเดียว)** เซฟจะเก็บไว้ในเบราว์เซอร์ของคุณ ถ้าอยากเล่นออนไลน์กับเพื่อน (ปาร์ตี้ ดันเจี้ยน เทรด) ต้องรันเซิร์ฟเวอร์เอง ดูวิธีด้านล่าง
แนะนำให้เล่นบน PC ผ่าน Chrome หรือ Edge

## เรื่องราว
คุณตื่นขึ้นมาท่ามกลางซากปรักหักพังในโลกเวทมนตร์ **"เอลิสมาร์"** โดยไม่มีความทรงจำ โลกนี้ถูก **"ม่านรัตติกาล"** ปกคลุม บนหลังมือคุณมีเครื่องหมายประหลาดของ "ผู้ถูกเรียก"

เรื่องราวไม่มีจุดจบ มีแต่การตามหาความลับของโลก ว่าคุณมาจากไหน และ **คุณคือแสงหรือความมืด** ทางเลือกในเนื้อเรื่องและการกระทำของคุณจะเปลี่ยนแนวทาง ☀ แสง / ☾ ความมืด ไปเรื่อย ๆ
(บรรยากาศได้แรงบันดาลใจจากอนิเมะ *Frieren* แต่ตัวละครและเนื้อเรื่องเป็นของเกมนี้เอง)

## รันเซิร์ฟเวอร์เองเพื่อเล่นออนไลน์
1. ติดตั้ง [Node.js 18+](https://nodejs.org)
2. ดาวน์โหลดโปรเจกต์นี้ แล้วดับเบิลคลิก `start-server.bat` หรือรัน `npm install` แล้วตามด้วย `npm start`
3. เปิด http://localhost:8080 เพื่อนในวง Wi-Fi เดียวกันเข้าได้ที่ `http://<IP เครื่องคุณ>:8080`
4. ถ้าจะให้เพื่อนที่อยู่ที่อื่นเข้าเล่น ใช้ [Cloudflare Tunnel](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/): `cloudflared tunnel --url http://localhost:8080`

การตั้งค่า Google Sign-In และการบันทึกการล็อกอินลง Google Sheet ทำใน `server/config.json` (สร้างให้อัตโนมัติตอนรันครั้งแรก) ขั้นตอนอยู่ใน `tools/google-apps-script.gs`

## โครงสร้างโปรเจกต์
```
shared/data.js     ข้อมูลเกม (ไอเทม มอนสเตอร์ NPC ภารกิจ ปริศนา เนื้อเรื่อง อาชีพ)
shared/core.js     ตรรกะโลก (AI มอนสเตอร์ ปาร์ตี้ เทรด ดันเจี้ยน) ใช้ร่วมกันทั้งเซิร์ฟเวอร์และโหมดออฟไลน์
server/server.js   HTTP + WebSocket, ระบบบัญชี, เซฟ, บันทึกลง Google Sheet
client/            ตัวเกม 3D (Three.js)
```
